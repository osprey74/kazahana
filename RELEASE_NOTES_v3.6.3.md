# kazahana v3.6.3

## English

### ✨ New Features

#### Profile links

Profiles now show the links their owners have added with Bluesky's new profile links feature. They appear below the bio as buttons with the site's icon and title (or the site's domain when there is no title). Click one to open it in your browser.

- kazahana shows the links but doesn't edit them. Add, edit, or reorder your links in the official Bluesky web app.
- Links follow the same rules as the official app. kazahana shows up to 10 links and only https links. It hides link shorteners, duplicate links, and links that your moderation settings would hide or blur.

#### Open a profile on the Bluesky web app

A new button next to the profile menu opens the profile on the Bluesky web app (bsky.app) in your browser. It is also shown on your own profile, so you can quickly jump to the web app to edit your profile or links.

### 🔧 Notes on cross-platform parity

These features are Desktop (Windows) only for now. Support status on other platforms is tracked in `docs/PLATFORM_MATRIX.md`.

## 日本語

### ✨ 新機能

#### プロフィールリンクの表示

Bluesky の新機能「プロフィールリンク」で登録されたリンクを、プロフィール画面に表示するようにしました。自己紹介の下に、サイトのアイコンとタイトル（タイトルがない場合はドメイン名）のボタンで並びます。クリックするとブラウザで開きます。

- kazahana では表示のみに対応しています。リンクの追加・編集・並べ替えは、公式の Bluesky Web 版で行ってください。
- 表示の規則は公式アプリと同じです。最大 10 件まで、https のリンクのみを表示します。短縮 URL、重複したリンク、モデレーション設定で非表示またはぼかし表示になるリンクは表示しません。

#### Web 版でプロフィールを開くボタン

プロフィール画面のメニューボタンの隣に、そのプロフィールを Bluesky Web 版（bsky.app）でブラウザで開くボタンを追加しました。自分のプロフィールにも表示されるため、プロフィールやリンクを編集したいときに Web 版へすぐ移動できます。

### 🔧 マルチプラットフォーム対応について

これらの機能は現時点では Desktop（Windows）のみが対象です。他のプラットフォームの対応状況は `docs/PLATFORM_MATRIX.md` で管理しています。
